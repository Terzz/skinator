# Skinator local

Aperçu et export de skins Dofus Retro (client 1.49.7), dessinés à partir des fichiers du client publiés sur le CDN
d'Ankama et rejoués dans le navigateur : classes, couleurs, 1 211 objets (coiffes, capes, familiers, boucliers),
animations de la fenêtre Caractéristiques, objets Polykrome, team, exports PNG et GIF.

Ouvrir `index.html`. Tout est local au navigateur (skins enregistrés, team, thème).

Projet de fan, sans lien avec Ankama. Dofus est une marque d'Ankama ; les dessins des personnages et des objets
leur appartiennent.
